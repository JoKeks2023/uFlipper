# Grenzen

Keine Firmwareänderung/Helferinstallation. NFC-Kartentest mangels geeigneter Karte und IR-Signaltest auf Nutzerwunsch ausgesetzt. Keine erfundenen Aufnahmen, Synchronisationszustände oder Vollbackups. Keine Simulatoren oder schweren lokalen Builds. Kein öffentlicher Release.

Dieser Oberflächenbauschritt folgt der aktuellen ausdrücklichen Nutzerfreigabe. Er ersetzt weder M2 (gemeinsamer Gerätebesitzer) noch A01/A18 oder die vollständige Kernabnahme. Live-Werkzeuge, weitere Layouts, Vollbackup, Firmware-Bibliothek, Cloud, MCP und Systemreader bleiben im vereinbarten Release-Umfang.
