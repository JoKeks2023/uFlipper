# Visuelle Entwürfe zur gemeinsamen Prüfung

27.10.2026. Alle drei Bilder sind Gestaltungsentwürfe mit ausdrücklich markierten Beispieldaten, keine Screenshots einer bereits funktionierenden App. Die bisherige App-Oberfläche wurde noch nicht ersetzt.

- `01_dashboard.png`: feste Seitenleiste, zentrale Arbeitsfläche, Power-/Backup-/Sync-Details.
- `02_infrared.png`: RAW-Pulsanalyse mit integrierter Anleitung und dauerhaftem Aufnahmestatus. Keine optische Spektrummessung behauptet.
- `03_settings.png`: Allgemein, Speicher, Cloud, Integrationen und Über/Credits.

Die Umsetzung dieser visuellen Richtung wartet auf die vereinbarte Nutzerprüfung. Backend-/Gerätearbeit kann unabhängig weiterlaufen. `render_proposals.py` erzeugt die Illustrationen mit lokalen macOS-Systemfonts und Pillow; es gehört nicht zur Produkt-Laufzeit.
