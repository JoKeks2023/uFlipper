# Umfang

NDEF zunächst read-only über ISO14443-4A / Type-4-Mapping 2 mit dem unveränderten freigegebenen Helfer. Erkennung, Capability Container, abhängige Dateiauswahl/READ-BINARY-Folge, begrenzte Aufnahme, verständliche Record-Anzeige. Andere Tagtypen benötigen eigene Transportpfade und bleiben im Gesamtumfang.

Mac-Reader über lokale PC/SC-Bridge am gemeinsamen NFC-/USB-Besitzer vorbereiten. Eigenständiges Betriebssystem-Reader-Bundle prüfbar bauen; unabhängiger OpenSC-Client bleibt Abnahmekriterium.
