# Prüfkriterien

- [ ] NDEF-Lesefolge und Parser prüfen Grenzen, gekürzte Daten und geänderte Länge.
- [ ] NDEF in nativer App wählbar, Originalaufnahme und Wiederöffnen.
- [ ] PPSE-Regressionen grün.
- [ ] Systemreader verwendet denselben USB-Besitzer, Stop und Aufzeichnung.
- [ ] Reader-Komponente als prüfbares Testartefakt vorbereitet.
- [ ] Echter Mac-Reader-Slot und unabhängiger Client beobachtet.
- [ ] Abhängige Kommandos, Kartenwechsel/Reset/Fehler mit passender Testkarte nachgewiesen.
