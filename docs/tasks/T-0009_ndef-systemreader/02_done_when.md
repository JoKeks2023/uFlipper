# Prüfkriterien

- [x] NDEF-Lesefolge und Parser prüfen Grenzen, gekürzte Daten und geänderte Länge.
- [x] NDEF in nativer App wählbar, Originalaufnahme und Wiederöffnen.
- [x] PPSE-Regressionen grün.
- [x] Systemreader verwendet denselben USB-Besitzer, Stop und Aufzeichnung.
- [x] Reader-Komponente als prüfbares Testartefakt vorbereitet.
- [ ] Echter Mac-Reader-Slot und unabhängiger Client beobachtet.
- [ ] Abhängige Kommandos, Kartenwechsel/Reset/Fehler mit passender Testkarte nachgewiesen.

Die ersten fünf Punkte betreffen Implementierung, Software-Verträge und native Start-/Stop-Abläufe ohne Karte. Sie ersetzen die beiden offenen physischen/systemweiten Abnahmen nicht.
