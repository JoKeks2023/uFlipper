# Prüfkriterien

- [x] Host-Prüfprogramm gebaut, bestehende Kerntests bestanden.
- [x] Nutzer hält freigegebenes Apple-Pay-iPhone bereit.
- [x] Aktivierung und zwei PPSE-Antworten tatsächlich beobachtet.
- [x] NFC/Helfer/RPC sauber beendet; Originalaufnahme integritätsgeprüft.
- [x] Befund und verbleibende Grenzen dokumentiert.

Zwei wiederholte SELECTs beweisen keine voneinander abhängigen Kartenkommandos und keinen PC/SC-Systemreader.
