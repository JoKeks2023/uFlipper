# Vorgaben

Keine zweite serielle Verbindung, keine Netzwerkschnittstelle. Keine automatische Freigabe, Helferinstallation, Readerregistrierung oder Firmwareänderung. Vollbackup-/Update-/Restore-Sperre erhalten. IR-Test verschoben, NDEF-Testkarte fehlt. Kein Release ohne Kernabnahme. Keine Simulatoren, Desktopbuilds in CI. Website-Arbeit nicht anfassen.

Die Gesamtfreigabe gilt für verfügbare Aktionen ohne zusätzliche pauschale Einzelbestätigungen. Hardwarekonflikte verlangen expliziten Stop anhand Auftrags-ID. Neue Helferversionen brauchen weiterhin eigene Freigabe. MCP-Zugang/Geheimnisse bleiben außerhalb des synchronisierbaren Workbench-Verzeichnisses.
