# Prüfkriterien

- [x] Raster und Inhalte teilen Ursprung, Grundmaß und Scrollbewegung.
- [x] Dashboard, IR und Einstellungen nativ bei normaler und kompakter Größe angesehen.
- [x] Bestehender nativer Klicklauf ohne neue QML-Laufzeitfehler.
- [x] Gebündeltes Paket geprüft; Screenshots und Grenzen dokumentiert.

Ein einzelner Zwischenfenster-Klicklauf bleibt als Untersuchungsbefund #1 offen; erfolgreiche Wiederholungen ersetzen keine Ursachenklärung. Die Paketprüfung für diesen Darstellungsbauschritt ist abgeschlossen. Keine vollständige Produkt-/Release-Abnahme.
